# retro-homebrew

New games for old machines, written to the metal. Each game lives under the
console it runs on, with its own build script, tools and tests.

## Library

| Console | Game | What it is | Folder |
|---|---|---|---|
| Tandy 1000 SL | **Yacht** | The classic dice game against "the Skipper" or a friend. 16-color graphics, three-voice music and digitized speech, in 8086 assembly. Boots from its own floppy image or runs under DOS/DeskMate. | [`tandy1000/yacht`](tandy1000/yacht) |
| Super Nintendo | **Yacht** | The same game rebuilt as a cartridge: sunset title with layered scrolling sea, a captain's-table game screen, tumbling dice, "Drunken Sailor" on a custom SPC700 driver, speech, battery-saved best score. 65816 assembly. | [`snes/yacht`](snes/yacht) |

## Building

Each game builds on its own from its folder with Git Bash on Windows:

```bash
cd snes/yacht && ./build.sh      # -> build/yacht.sfc
cd tandy1000/yacht && ./build.sh # -> build/YACHT.COM, build/YACHT.DSK
```

What each needs:

- **Tandy 1000 Yacht:** [NASM](https://www.nasm.us/) (default `/c/msys64/ucrt64/bin/nasm.exe`, or set `NASM`), Node. Run `tools/make_speech.sh` once first to render the speech with Windows SAPI.
- **SNES Yacht:** [WLA-DX v10.7](https://github.com/vhelin/wla-dx) (default `$HOME/tools/wla-dx/wla_dx_v10.7_Win64`, or set `WLA_DX`), Node, Windows (for the speech). Its tests run headless in [Mesen 2](https://github.com/SourMesen/Mesen2) (portable, at `$HOME/tools/mesen2` or set `MESEN_DIR`):

  ```bash
  cd snes/yacht && node --test tools/test && tests/run.sh
  ```

Nothing is downloaded at build time and there are no npm dependencies: every
graphic, instrument and table is generated by the scripts in each game's
`tools/` folder.

## Layout

```
<console>/<game>/     one game for one machine: build.sh, src/, tools/, tests/
docs/superpowers/     design notes and implementation plans
```

The SNES port reads its music and speech lines straight from the Tandy
source (`tandy1000/yacht/src/data.asm`, `tandy1000/yacht/tools/speech.txt`),
so the two versions stay in step. Where the SNES differs on purpose it says so:
its own wording for a phrase goes in `snes/yacht/tools/speech_snes.txt`, and its
straights are the poker-dice kind (see `snes/yacht/README.txt`).

Adding a game: make `<console>/<game>/` with its own `build.sh` and a README,
and add a row to the table above.
